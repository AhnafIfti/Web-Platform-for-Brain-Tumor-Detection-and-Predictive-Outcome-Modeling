Connect your trained checkpoint

Provide the trained two-channel Swin-Tiny U-Net weights at ml_models/checkpoints/swin_tiny_unet.pth, or set MODEL_CHECKPOINT_PATH. Accepted formats are a PyTorch state dictionary or a dictionary containing state_dict or model_state_dict.

Start python manage.py run_analysis_worker alongside the web server. Restart the worker after changing the model. Missing or incompatible weights produce a clear error; no substitute prediction is used.
